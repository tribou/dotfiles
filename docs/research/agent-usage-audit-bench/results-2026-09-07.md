### Loophole the baseline exposes

All three agents reproduced their skill's existing numbered steps with
100% fidelity (every non-bolded check passed) and invented **nothing**
beyond what was explicitly listed — they neither attempted a usage-audit
step nor rationalized skipping one; it is a clean, total omission, not a
mangled attempt. **Correction the skill text must make explicit:** because
these agents execute every explicitly numbered instruction but never
invent an unstated one, the fix is to add the audit call as its own
explicitly numbered, non-optional step at the exact ordering position
relative to steps the agent already follows precisely (e.g., "after the
prefix is stripped, before the URL is shown" for S1; "after PR
verification, before printing the URL" for S2; "before stopping" for S3)
— not a footnote, not an aside, and not left implicit in a "Common
Mistakes" row alone. Ordering and target (`issue:<N>` vs `pr:<M>`) must be
spelled out inline at the exact step, since nothing here suggests these
agents would infer either correctly on their own.
