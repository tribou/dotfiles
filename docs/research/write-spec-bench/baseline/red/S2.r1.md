# Remove deprecated docker-machine functions from commands.sh

## Summary
Remove the legacy `docker-machine` helper functions from `commands.sh`. Docker Machine was archived upstream in 2021 and is no longer maintained, so these helpers are dead code that can't be relied on.

## Background
Docker Machine was deprecated and its repository archived in 2021. Any functions in `commands.sh` that wrap or depend on `docker-machine` target a tool that gets no further fixes and is no longer part of a normal Docker setup. Keeping them adds clutter and suggests a workflow that is no longer supported.

## Scope
- Delete all functions, aliases, and helper variables in `commands.sh` that invoke or exist only to support `docker-machine`.
- Remove any comments or section headers that only describe the removed code.
- Remove references to the removed functions elsewhere in the repo (other shell files, docs, README, completions).

## Out of scope
- Changes to non-`docker-machine` Docker functions in `commands.sh`.
- Adding replacements. If one is needed, file a separate item.

## Acceptance criteria
- [ ] `grep -rni "docker-machine\|docker_machine" .` returns no matches in `commands.sh` or in anything that sources it, except for intentional historical notes, if any.
- [ ] No removed function name is still called from elsewhere in the repo.
- [ ] `bash -n commands.sh` passes, and sourcing the file in a fresh shell produces no errors or warnings.
- [ ] The remaining Docker-related functions still work as before.
- [ ] The README and other docs no longer mention the removed functions.

## Notes
- Before deleting, list the affected functions and check their usage with `git grep`, including dotfiles that source `commands.sh`, such as shell rc files.
- If any function is still used on a machine you care about, decide whether to migrate it to the Docker CLI with contexts, or to Docker Desktop, Colima, or Podman, before removal.
