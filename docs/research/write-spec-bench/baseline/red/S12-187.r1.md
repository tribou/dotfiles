# perf(test): docker-based tests running very slow locally

## Summary
Local Docker-based test execution (`just test`) takes ~3m 42s due to redundant downloads, non-idempotent compilation, and full Homebrew provisioning. Additionally, `just test` fails from linked Git worktrees (#189) because of broken `.git` pointer resolution and Git safe-directory restrictions. This work reduces local test runtime to ~24s–36s (6x–9x speedup), preserves test integrity, adds a full clean-state test path, and fixes test execution in linked worktrees.

## Motivation / Context
`just test` took 3m 41.7s locally, with 92.8% of the time spent in Ansible provisioning:

1. The ephemeral container reinstalled Homebrew on Linux from scratch, plus 27 formulae and gcc (~89s). None of this is asserted by `goss.yaml` or the Bats integration tests.
2. `mise install` re-downloaded runtimes (node, go, ruby), 18 global npm packages, and recompiled Ruby native gems with no volume caching (~41s).
3. `apt` ran an unconditional `update_cache: true` for missing Linux prereqs (~26s).
4. `roles/dotfiles/tasks/nvim.yml` checked a nonexistent path (`creates: "{{ dotfiles_home }}/dev/go/bin/gopls"`) instead of using `which gopls` / `$GOBIN`, so `gopls` was recompiled from source on every run (~15s).
5. Linked worktree failure (#189): running `just test` from a linked worktree (e.g. under `.worktrees/`) failed at `dotfiles : Clone TPM` with `fatal: not a git repository`. In a linked worktree `.git` is a pointer file to the common git directory (`<main-repo>/.git/worktrees/...`). The container only mounted `.:/dotfiles`, so Git could not resolve the host's common git directory.

Profiling showed RAM was not the bottleneck (peak container RAM ~1.06GB with 8GB free on the host, no swap activity). Burst CPU and network I/O were heavily saturated.

## Requirements
- Local `just test` finishes in under 45 seconds (target ~25s–35s) on cached runs.
- Fix the `gopls` idempotency check in `roles/dotfiles/tasks/nvim.yml` to check actual binary existence (`which gopls`).
- Add `cache_valid_time: 86400` to the apt task in `roles/dotfiles/tasks/prereqs.yml`.
- Mount persistent `.ci-cache/` volumes in `docker-compose.yml` for mise runtimes/cache, tmux plugins, and go/coc.
- Set default `DOTFILES_ANSIBLE_EXTRA_ARGS: "--skip-tags brew,rust"` in `docker-compose.yml`, matching GitHub Actions CI behavior in `ubuntu-tests.yml`.
- Add a fast `ansible-playbook --syntax-check` to `just test-unit` to guard against regressions in the skipped roles (`brew.yml`, `rust.yml`).
- Add a `just test-clean` recipe that wipes `.ci-cache/` and runs a full cold test without `--skip-tags`.
- Support linked Git worktrees (#189):
  - In `justfile`, resolve the common Git directory (`git rev-parse --path-format=absolute --git-common-dir`) and bind-mount it read-only into the container for `test`, `test-clean`, and `dev`.
  - Configure `safe.directory: "*"` in the container environment (`docker-compose.yml` and `Dockerfile`) so cross-UID / worktree access does not hit dubious-ownership errors.
- Docker build hygiene: add `.worktrees/`, `.claude/`, and `.ci-cache/` to `.dockerignore` so child worktrees don't inflate the build context.

## Non-goals
- Rewriting the Docker base image to bake in all user runtimes (keeps flexibility for local dotfile hacking).
- Modifying remote CI workflows beyond aligning flags (GitHub Actions already skips brew).
- Changing dotfiles installation logic on macOS hosts.

## Acceptance criteria / Testing
- All 54 Goss infrastructure assertions pass in `just test`.
- All 25 Bats integration tests pass in `just test`.
- `just test-unit` includes syntax validation across all Ansible task files.
- `just test-clean` clears `.ci-cache/` and completes a full cold-start bootstrap.
- `just test` passes from both the primary checkout and a linked worktree (`.worktrees/`).
- Benchmark confirms runtime drops from ~3m 42s to ~25s–35s on cached runs.

## Design notes / Decisions
- **RAM is not a constraint.** Bottlenecks are Homebrew download/compile (89s), uncached mise runtimes/gems (41s), uncached apt update (26s), and the gopls recompilation bug (15s).
- **Integrity risk is low and accepted.**
  - The gopls and apt changes are pure idempotency fixes.
  - Skipping brew/rust matches existing GitHub Actions CI, since Goss and Bats don't test brew packages. The syntax check in `test-unit` covers the skipped roles.
  - Volume caching shifts local runs to idempotent convergence, consistent with the existing `.ci-cache/nvim` precedent, and the cache can be wiped on demand via `just test-clean`.
- **Clean-state safeguard** is a dedicated `just test-clean` recipe rather than a flag or automatic trigger.
- **Worktree fix is folded into this work** (#189): dynamic common-git-dir mount plus `safe.directory: '*'`.
- **Child worktree test isolation:** accidentally running child worktree tests from the parent has not been an issue, because the Bats and Goss runners use explicit non-recursive paths (`tests/*.bats`, `tests/integration/`). This change enables intentionally running tests from inside a child worktree, which previously broke. The `.dockerignore` additions keep worktree files out of Docker build contexts.
