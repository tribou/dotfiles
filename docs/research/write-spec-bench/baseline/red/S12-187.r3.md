# perf(test): docker-based tests running very slow locally

## Summary
Local Docker-based test execution (`just test`) takes ~3m 42s due to redundant downloads, non-idempotent compilation, and full Homebrew provisioning. Additionally, `just test` fails from linked Git worktrees (#189) because of broken `.git` pointer resolution and Git safe-directory restrictions.

This item covers optimizations to reduce local test runtime to ~24s–36s (6x–9x speedup) while preserving test integrity, adding a full clean-state test option, and fixing test execution from linked worktrees.

## Motivation / Context
A local `just test` run took 3m 41.7s, with 92.8% of the time spent in Ansible provisioning:

1. **Homebrew (~89s):** The ephemeral container reinstalls Homebrew on Linux from scratch, plus 27 formulae and gcc. None of this is asserted by `goss.yaml` or the Bats integration tests.
2. **mise (~41s):** `mise install` re-downloads runtimes (node, go, ruby) and 18 global npm packages, and recompiles Ruby native gems, with no volume caching.
3. **apt (~26s):** An unconditional `update_cache: true` runs for missing Linux prereqs.
4. **gopls (~15s):** `roles/dotfiles/tasks/nvim.yml` checks a nonexistent path (`creates: "{{ dotfiles_home }}/dev/go/bin/gopls"`) instead of the real binary (`which gopls` / `$GOBIN`), so `gopls` is recompiled from source on every run.
5. **Linked worktrees (#189):** Running `just test` from a linked worktree (e.g. under `.worktrees/`) fails at `dotfiles : Clone TPM` with `fatal: not a git repository`. In a linked worktree `.git` is a pointer file to the common git directory (`<main-repo>/.git/worktrees/...`). The container only mounts `.:/dotfiles`, so Git cannot resolve the host's common git directory.

Profiling showed RAM is not the bottleneck (peak container RAM ~1.06GB, 8GB free on host, no swap activity). Burst CPU and network I/O are heavily saturated.

## Requirements

### Performance
- Local `just test` finishes in under 45 seconds (target ~25s–35s) on cached runs.
- Fix the `gopls` idempotency check in `roles/dotfiles/tasks/nvim.yml` to check actual binary existence (`which gopls`).
- Add `cache_valid_time: 86400` to the apt task in `roles/dotfiles/tasks/prereqs.yml`.
- Mount persistent `.ci-cache/` volumes in `docker-compose.yml` for mise runtimes/cache, tmux plugins, and go/coc.
- Set default `DOTFILES_ANSIBLE_EXTRA_ARGS: "--skip-tags brew,rust"` in `docker-compose.yml`, matching GitHub Actions CI behavior in `ubuntu-tests.yml`.

### Safeguards
- Add a fast syntax check (`ansible-playbook --syntax-check`) to `just test-unit` to guard against regressions in the skipped roles (`brew.yml`, `rust.yml`).
- Add a `just test-clean` recipe to the `justfile` that wipes `.ci-cache/` and runs a full cold test without `--skip-tags`.

### Linked worktree support (#189)
- In the `justfile`, resolve the common Git directory (`git rev-parse --path-format=absolute --git-common-dir`) and bind-mount it read-only into the container for `test`, `test-clean`, and `dev`.
- Configure `safe.directory: "*"` in the container environment (`docker-compose.yml` and `Dockerfile`) to avoid dubious-ownership errors across UIDs and worktrees.

### Docker build hygiene
- Add `.worktrees/`, `.claude/`, and `.ci-cache/` to `.dockerignore` so child worktrees do not inflate the build context.

## Non-goals
- Rewriting the Docker base image to bake in all user runtimes (keeps flexibility for local dotfile hacking).
- Modifying remote CI workflows beyond aligning flags (GitHub Actions already skips brew).
- Changing dotfiles installation logic on macOS hosts.

## Acceptance criteria / Testing
- [ ] All 54 Goss infrastructure assertions pass in `just test`.
- [ ] All 25 Bats integration tests pass in `just test`.
- [ ] `just test-unit` runs syntax validation across all Ansible task files.
- [ ] `just test-clean` clears `.ci-cache/` and completes a full cold-start bootstrap.
- [ ] `just test` passes from both the primary checkout and a linked worktree (`.worktrees/`).
- [ ] Benchmark shows runtime dropping from ~3m 42s to ~25s–35s on cached runs.

## Decisions / Notes
- **Integrity risk is low and accepted.** The gopls and apt changes are pure idempotency fixes. Skipping brew/rust matches existing GitHub Actions CI, since Goss and Bats do not test brew packages, and the `test-unit` syntax check covers the skipped roles. Volume caching moves local runs to idempotent convergence, consistent with the existing `.ci-cache/nvim` precedent, and the cache can be wiped on demand.
- **Clean-state fallback:** a dedicated `just test-clean` recipe (rather than a flag or env var) clears `.ci-cache/` and runs without `--skip-tags`.
- **Worktree fix is folded in** so `just test` works seamlessly from worktrees.
- **Child worktrees are not accidentally tested from the parent.** Bats and Goss runners use explicit non-recursive paths (`tests/*.bats`, `tests/integration/`). The fix enables *intentionally* running tests from inside a child worktree, which previously broke. The `.dockerignore` additions keep worktree files out of build contexts.
