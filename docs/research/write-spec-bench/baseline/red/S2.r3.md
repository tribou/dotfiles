# Remove deprecated docker-machine functions from commands.sh

## Summary
Remove the legacy `docker-machine` helper functions from `commands.sh`. Docker Machine was archived in 2021 and is no longer maintained, so these helpers are dead code that can mislead users.

## Background
Docker Machine was deprecated and its repository archived in 2021. It receives no updates, and current Docker workflows use Docker Desktop, Docker Engine with contexts (`docker context`), or other tooling. Keeping the functions adds clutter and suggests a supported workflow that no longer exists.

## Scope
- Delete every function in `commands.sh` that wraps or depends on `docker-machine`, including any helpers, aliases, or completions that exist only to support them.
- Remove references to the deleted functions elsewhere in the repo (other shell files, docs, README, comments).

## Out of scope
- Adding replacements, such as `docker context` helpers. File a separate item if wanted.
- Changes to unrelated Docker functions in `commands.sh`.

## Acceptance criteria
- [ ] `commands.sh` contains no `docker-machine` invocations or functions that exist solely to wrap it.
- [ ] `grep -ri "docker-machine"` across the repo returns no stale references. Any intentional mentions, such as a changelog note, are documented.
- [ ] `commands.sh` still sources cleanly (`bash -n commands.sh` and a fresh shell start with no errors).
- [ ] Remaining functions in `commands.sh` do not call any removed function.

## Notes
- Before deleting, check whether any removed function is used by other scripts or dotfiles, such as shell rc files or aliases.
- Confirm that no active machine or environment still depends on these functions.
